# Enforce a cited answer contract

Every response will contain an answer with claim-level citations, explicit
assumptions, a source list containing document version, section or clause, page,
and exact supporting excerpts, and a limitations section. Responses must
distinguish direct source statements from synthesis, disclose conflicting
sources, cite source passages rather than graph facts, and abstain when no
verified claim answers the question; compliance responses use the same contract
for each checklist item.
